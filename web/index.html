Agent workflow

From source document to reviewed workbook

  1. Inspect & route.

    Upload up to 50 pages / 40 MB. Automatic mode uses native text where possible and local OCR for scans.

  2. Extract & validate.

    Tables, headers and continuation pages are detected. Arithmetic, totals, balances and integrity checks create review findings.

  3. Review the evidence.

    Select a row to locate its source. Resolve cells or acknowledge outstanding findings with a review note. OCR confidence is not extraction accuracy.

  4. Export a recorded decision.

    Draft exports are labelled unreviewed. Completing review records the current data snapshot; a later correction resets review. OCR retries retain the previous run.

Always check critical figures. The included synthetic benchmarks do not establish accuracy on unseen documents.
