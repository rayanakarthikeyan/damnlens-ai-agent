DamnLens AI Agent | INCUXAI Challenge 2026

1. Install 64-bit Python 3.12 from https://www.python.org/downloads/
   if it is not already installed. Local AI uses a CPU and needs no API key.
2. Extract the full project ZIP to a writable folder.
3. Windows: double-click START_DAMNLENS.cmd.
   macOS/Linux: open a terminal in this folder and run: sh start.sh
   First setup needs internet for pinned Python packages. Later local runs work offline.
4. The local browser workspace opens after server readiness. Keep the terminal
   open. If port 8765 is occupied, the launcher chooses another and prints it.
5. Choose Local AI (default), then upload a PDF/image (50 pages / 40 MB), or
   run an Evaluation fixture. Sample buttons always run locally.
   Inspect Data & source, Validation and Page coverage. Use Text size > Large
   for a larger interface. Review source values before exporting real data.
6. Optional: copy .env.example to .env, set GEMINI_API_KEY and restart.
   Select Gemini-assisted AI, a page scope and request limit, then authorize
   sending selected full pages to Google. Free/paid API tiers and quotas apply.
   Inspect AI workflow for candidates, usage, proposals and skipped pages.
   Main values are never overwritten automatically. Live dummy-page results: reports/GEMINI_EVALUATION.md.
   See docs/WORKFLOWS.md for architecture, costs, limitations and recovery.

Reproducible judge checks (after first setup):
  Windows: START_DAMNLENS.cmd --judge-test --offline
  macOS/Linux: sh start.sh --judge-test --offline

Diagnostics only:
  Windows: START_DAMNLENS.cmd --check --offline
  macOS/Linux: sh start.sh --check --offline

Eight checks compare all three samples with exact truth, inspect Excel,
test nested headers and cross-page source parts, preserve duplicate records
through 50 pages, reject 51 pages and resume verified page checkpoints.
They return a nonzero exit code on failure. Report: reports/judge-check-latest.json

Development results are not a guarantee for hidden PDFs. Printed English is
the evaluated OCR target. Supported multi-line/merged layouts keep source
geometry and review warnings. Arbitrary nesting, changing schemas and severe
scan damage can still require manual reconstruction.

On an interrupted extraction, Resume extraction reuses verified completed
pages. Retry OCR starts a fresh OCR run. No API key or cloud upload is needed.

Press Ctrl+C in the console to stop the application.
