DamnLens AI Agent | INCUXAI Challenge 2026

1. Install 64-bit Python 3.12 from https://www.python.org/downloads/
   if it is not already installed. A CPU is sufficient; no API key is needed.
2. Extract the full project ZIP to a writable folder.
3. Windows: double-click START_DAMNLENS.cmd.
   macOS/Linux: open a terminal in this folder and run: sh start.sh
   First setup needs internet for pinned Python packages. Later runs are offline.
4. The local browser workspace opens after server readiness. Keep the terminal
   open. If port 8765 is occupied, the launcher chooses another and prints it.
5. Run an Evaluation fixture, or upload your own PDF/image (50 pages / 40 MB).
   Inspect Data & source, Validation and Page coverage. Use Text size > Large
   for a larger interface. Review source values before exporting real data.

Reproducible judge checks (after first setup):
  Windows: START_DAMNLENS.cmd --judge-test --offline
  macOS/Linux: sh start.sh --judge-test --offline

Diagnostics only:
  Windows: START_DAMNLENS.cmd --check --offline
  macOS/Linux: sh start.sh --check --offline

The checks compare all three samples with exact ground truth, inspect Excel
exports, preserve duplicate records through 50 pages and reject 51 pages.
They return a nonzero exit code on failure. Report: reports/judge-check-latest.json

Synthetic development results are not a guarantee for hidden PDFs. Printed
English is the evaluated OCR target. Complex nested/merged layouts, changing
multi-line headers and severe scan damage can require manual reconstruction.

Press Ctrl+C in the console to stop the application.
